Hostkind

Self-hosted control plane for game servers. AGPL-3.0, Windows and Linux installers.

What it is

One local Node.js process supervises game servers, streams live consoles, tracks memory and player counts, and runs verified backups and updates with no Docker, external database, or cloud account. World files stay on disk.

Hard parts

  • Single process: state lives in SQLite, and long-running work is stored as jobs so installs and upgrades survive crashes.
  • Per-game modules: Minecraft, Terraria, Valheim, and Palworld each install, boot, and stop differently, so game-specific logic lives in lib/modules/ instead of the supervisor.
  • Verified backups: archives are verified after creation, retention rules run automatically, and destructive actions require a second confirmation token.
  • Packaging: Electron desktop builds for Windows and Linux. The Windows installer is unsigned, so the docs recommend the portable zip until code signing is added.
