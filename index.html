Work

Hostkind

A self-hosted control plane for game servers and other long-running processes. Start, stop, monitor, update and back up servers from one local app, with no cloud account and no external database. Live consoles, metrics, a file manager, scheduled backups, users, roles and an audit log, in one Node.js process.

The hard part: keeping a single process while Minecraft, Terraria, Valheim and Palworld all install, start and shut down in their own way.

Node.js 22, SQLite for state, React for the panel, Electron for the desktop build. AGPL-3.0, installers for Windows and Linux.

Ene

A Spanish tutor for Korean speakers. You write a sentence and ask in Korean whether it is right; it rewrites the sentence, names what changed, explains the rule in Korean and gives you one exercise. The demo runs on a Cloudflare Worker. The tutor behind it is a fine-tune of Gemma 4 E2B, trained on one 12 GB laptop GPU.

The hard part: getting a 2B model to stop correcting sentences that were already correct, then proving it on a test set it had never seen.

Python and PyTorch for training, Ollama and llama.cpp for running it, Cloudflare Workers and KV for the demo app. On a frozen 208-item set it scores 177/208 against 123/208 for the stock model.

AJFit

A training app for a personal trainer and their clients. Clients log sessions, see progress per exercise and send feedback afterwards. The trainer opens a list sorted by what needs attention: unanswered feedback first, then whoever stopped training. Meal ideas come from what the client already has at home.

The hard part: making the coach's screen useful in ten seconds, when the honest answer is a sorted list of who needs a reply.

React and TypeScript, Hono on Cloudflare Workers, D1 for the database. Private repo, paying client.

The Riloox video pipeline

The editing pipeline behind my YouTube channel. A voice-over and a shot list go in, a rendered timeline comes out: cuts on word timings, sound effects and music beds levelled to -16 LUFS, thumbnails built from licensed fonts and my own doodle. The licence rule is the strict part, every asset has to be usable without attribution and without buying anything.

The hard part: landing a sound effect on the exact word of a punchline, and keeping the asset library provably clean.

Python for the build scripts, MLT and melt for rendering, ffmpeg for audio, ImageMagick for thumbnails.
